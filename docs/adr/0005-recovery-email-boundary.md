# Почта аккаунта и почта восстановления имеют разные роли

В MVP почта аккаунта — это уникальный подтверждённый адрес, полученный при регистрации через Yandex ID либо добровольно подтверждённый владельцем password-аккаунта. Только у password-аккаунта этот адрес дополнительно становится почтой восстановления и позволяет самостоятельно сбросить локальный пароль; пользователь Yandex ID восстанавливает доступ средствами Яндекса. Отсутствие почты у password-аккаунта не блокирует обучение или игру: после первого игрового результата пользователь получает предложение защитить аккаунт и предупреждение, что без подтверждённой почты самостоятельное восстановление невозможно. Почта не становится логином, каналом маркетинговых или игровых уведомлений. Такое разделение учитывает адрес из Yandex ID, сохраняет понятные способы восстановления и не создаёт локальный пароль для OAuth-аккаунта.

Профиль показывает одну карточку «Защита аккаунта», которая буквально различает состояния: почта отсутствует; ожидается код; адрес подтверждён, но находится в 24-часовом периоде защиты; Recovery Email активен; выполняется замена с отдельными статусами старого и нового адресов; адрес управляется через Яндекс ID; отправка приостановлена из-за заблокированного почтового сервиса. Для каждого состояния видны последствие и следующий безопасный шаг. После первоначального ввода адрес маскируется в обычном интерфейсе; полный адрес не используется как постоянная подпись профиля.
