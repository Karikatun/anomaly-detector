# Russian Launch Data And Authentication Boundary

The initial product is operated by a Russian citizen for a Russian audience. Store Russian users' personal data and match history in Russia, target Yandex Cloud for production deployment, and use Yandex ID and VK ID as primary sign-in methods. Do not depend on foreign email for registration or treat Telegram OAuth as a compliant primary path without a dedicated legal review; this makes the launch constraints explicit before identity, data, and deployment choices become costly to reverse.
