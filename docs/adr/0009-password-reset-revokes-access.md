# Восстановление пароля отзывает весь прежний доступ

Запрос восстановления password-аккаунта принимает логин, а не почту, и всегда возвращает одинаковый внешний ответ независимо от существования аккаунта, наличия подтверждённой почты и способа входа. Письмо содержит одноразовую ссылку с длинным случайным токеном: в базе хранится только его хеш, срок действия составляет 15 минут, открытие страницы ничего не меняет, а токен потребляется атомарно только при отправке нового пароля. Отдельное действие позволяет вместо ссылки предъявить Recovery Code вместе с логином, не раскрывая состояние аккаунта до успешной проверки. Страница не загружает аналитику или сторонние ресурсы и запрещает передачу URL через `Referrer-Policy: no-referrer`; новый запрос аннулирует прежнюю ссылку. Успешное восстановление атомарно заменяет пароль, отзывает все активные сессии на всех устройствах и аннулирует остальные почтовые коды, ссылки и Recovery Code. Пользователь получает уведомление на почту, когда отправка безопасно доступна, и входит заново с новым паролем без автоматического создания сессии. Это не позволяет использовать форму для разведки аккаунтов, расходовать ссылку почтовым предпросмотром или сохранить ранее открытый доступ после возврата аккаунта владельцем.
