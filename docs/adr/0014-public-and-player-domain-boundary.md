# Публичный сайт и приложение используют разные поддомены

Корневой `https://anomaly-detector.ru` принадлежит публичному индексируемому лендингу, а `https://www.anomaly-detector.ru` постоянно перенаправляет на него. Регистрация, вход, обучение, профиль и игра размещаются на `https://app.anomaly-detector.ru`; API остаётся на `https://api.anomaly-detector.ru`, операторская зона — на `https://ops.anomaly-detector.ru`. Главный CTA лендинга передаёт приложению намерение продолжить одиночное обучение после регистрации. При переходе с прежней схемы известные игровые маршруты корневого домена получают адресные перенаправления с сохранением path/query, а не превращаются в ошибки или общую переадресацию на главную.

Пока открыт immediate rollback window, legacy-переходы root → app остаются временными и получают `Cache-Control: no-store`: иначе закешированный permanent redirect образует цикл с rollback-профилем app → root. Перевод этих адресных переходов в permanent возможен только отдельным owner-controlled изменением после явного закрытия rollback window и повторной проверки Caddy; постоянный `www` → root не затрагивает этот переходный инвариант.

Разделение делает корневой домен полноценной статической поисковой поверхностью и одновременно задаёт явную границу для индексации, кеширования и персональных данных. Миграция выпускается согласованно с DNS и TLS, CORS, OAuth redirect URI, cookie-областью, Content Security Policy, юридическими URL, публичными ссылками и runbook развёртывания; доступность старых ссылок проверяется до переключения.
