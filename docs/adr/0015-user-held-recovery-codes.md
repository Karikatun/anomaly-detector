# Владелец хранит резервные коды восстановления

После активации Recovery Email password-аккаунт один раз показывает владельцу набор из восьми Recovery Code. В базе хранятся только их криптографически защищённые производные; каждый код одноразовый. Recovery Code вместе с логином позволяет восстановить пароль либо вместо кода со старой почты подтвердить замену недоступного Recovery Email. После применения отзываются все сессии, ссылки, почтовые коды и оставшиеся Recovery Code, а новый адрес проходит обычное подтверждение и 24-часовой период защиты. Перевыпуск набора требует текущий пароль и код с действующего Recovery Email.

Поддержка и администратор не видят Recovery Code, не могут выпустить их за пользователя и не могут вручную назначить новую почту. Это создаёт проверяемый пользовательский путь при потере ящика или блокировке Approved Mail Service, не превращая социальную проверку через поддержку в обход факторов владения.

Набор показывается только при выпуске на отдельном экране с действиями «Скопировать», «Скачать .txt» и «Распечатать». Перед закрытием пользователь подтверждает сохранение; он может явно пропустить этот шаг, чтобы защита аккаунта не блокировала игру, но получает предупреждение, что текущий набор повторно показать нельзя. Коды не отправляются по почте и не попадают в аналитику, логи или снимки интерфейса. Позднее доступен только выпуск нового набора с текущим паролем и кодом с Recovery Email, который одновременно уничтожает прежний набор.
