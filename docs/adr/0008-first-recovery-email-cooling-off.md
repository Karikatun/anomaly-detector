# Первая почта восстановления активируется с задержкой

У password-аккаунта без прежней почты первая привязка требует текущий пароль и одноразовый код с нового адреса, но становится пригодной для восстановления только через 24 часа. До активации все сессии, созданные раньше запроса, показывают предупреждение и позволяют отменить привязку с отзывом остальных сессий; новая сессия таким доверием не обладает. Задержка не устраняет риск полностью, поскольку исходного независимого фактора ещё нет, но даёт настоящему владельцу окно для обнаружения и отмены закрепления злоумышленника с украденными логином и паролем.
