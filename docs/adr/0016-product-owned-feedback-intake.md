# Обратная связь хранится в управляемом продуктом контуре

Отдельная кнопка «Обратная связь» в меню открывает собственную форму приложения, а не встроенную или внешнюю Яндекс Форму. Feedback Report с категорией «Ошибка» или «Предложение», пользовательским описанием и минимальным безопасным техническим контекстом принимает backend, сохраняет в PostgreSQL и возвращает публичный номер обращения. Защищённый раздел `adminapp` показывает оператору очередь со статусами `new`, `in_review`, `resolved` и `rejected` и только перечисленные ниже workflow-команды. На `support@anomaly-detector.ru` может отправляться только уведомление с номером и ссылкой в защищённую админку, без текста обращения и персональных данных.

Обращение не создаёт GitHub Issue автоматически. Если требуется разработка, оператор вручную переносит только очищенное техническое содержание без пользовательских данных. По умолчанию обращение не хранит связь с аккаунтом или контакт для ответа; их можно добавить только отдельным добровольным действием пользователя. Account Email не становится support-контактом и не используется автоматически. Вложения откладываются до появления проверенного частного хранилища, проверки форматов, удаления и антивирусного контура.

Яндекс Формы не используются как основной канал, потому что их текущий контракт не позволяет удалить отдельные ответы и не даёт продукту достаточного контроля над сроком хранения случайно переданных персональных данных. Внешняя форма допустима только для отдельного полностью анонимного опроса без файлов, контактов, идентификаторов и автоматического контекста после повторной проверки условий провайдера.

Контракт провайдера проверен 19 августа 2026 года по официальным страницам [получения и удаления ответов](https://yandex.ru/support/forms/ru/answers) и [условий Яндекс Форм](https://yandex.ru/legal/forms_termsofuse/ru/); перед любым будущим использованием проверка повторяется.

Форма доступна авторизованным игрокам и ограничена пятью принятыми обращениями в сутки на аккаунт и двадцатью на доверенный IP. Проблемы до входа направляются на `support@anomaly-detector.ru`; сообщения об уязвимостях и запросы субъекта персональных данных используют отдельные каналы. Перед отправкой интерфейс просит не включать пароли, коды, токены и чужие данные.

Обращения в состояниях `new` и `in_review` хранятся не более 180 дней. Для `resolved`, `rejected` и обращений, очищенное содержание которых перенесено в GitHub Issue, текст, добровольный контакт и связь с аккаунтом удаляются через 30 дней. Оператор заранее видит приближение срока. Обезличенные месячные количества по категориям и итоговым статусам могут храниться 13 месяцев; они не позволяют восстановить содержание или автора.

Оператор обрабатывает очередь только перечисленными аудируемыми командами: взять в работу, решить, отклонить с причиной, записать номер вручную созданной очищенной GitHub Issue и досрочно удалить добровольный контакт. Исходное пользовательское содержание и авторство не редактируются, письма из админки не отправляются, внешние задачи автоматически не создаются.

Первый выбор формы — «Ошибка» или «Предложение». Ошибка запрашивает, что произошло, шаги воспроизведения, ожидаемый результат и возможность продолжить игру; предложение — желаемое изменение и решаемую им проблему. Backend автоматически принимает только build SHA, шаблон маршрута без идентификаторов комнаты и матча, грубый класс устройства и браузера и безопасный `error_id`; сырой `User-Agent`, полный URL, IP, логи, токены и игровое состояние в обращение не входят. Отдельные необязательные действия позволяют предоставить контакт для ответа и разрешить связь с аккаунтом для диагностики; ни одно из них не использует Recovery Email автоматически. После приёма пользователь получает копируемый публичный номер обращения.

MVP не содержит раздела «Мои обращения», переписки или пользовательского статуса. После отправки интерфейс прямо объясняет, что индивидуальные статусы не публикуются: без добровольного контакта канал односторонний, а при наличии контакта оператор может ответить вручную с `support@anomaly-detector.ru`, указав номер обращения. Операторский статус остаётся внутренним; исправления сообщаются пользователям только через общий продуктовый канал выпуска, когда он появится.
