# Проверка целостности project skills

Перед применением skill из `.agents/skills` выполните `bun run security:skills`.
Эта же проверка входит в `test:tooling`, существующий pre-commit и CI. Ошибка
останавливает эти проверки; изменённый пакет нельзя применять до review.

`.security/skills.json` фиксирует локально проверенные версии всех пакетов.
Проверяются все файлы: `SKILL.md`, скрипты, тесты, references и ресурсы.
Добавление, удаление или изменение файла меняет digest. Незакреплённые пакеты,
симлинки, специальные файлы и превышение лимитов отклоняются. Исключений для
bytecode нет: запускайте Python с `-B`, а тесты — через `bun run test:skills`.

Digest — SHA-256 от UTF-8 JSON массива записей `{path,bytes,sha256}`. Обход
каталогов рекурсивный; на каждом уровне имена сортируются по UTF-8 байтам.
Пути внутри пакета используют `/`; `bytes` — размер файла, `sha256` — хеш
его содержимого. JSON сериализуется без отступов с указанным порядком ключей.
Переименование файла также меняет digest.

При согласованном обновлении сначала проверьте diff **всего пакета**, затем
запустите его тесты. Для расчёта проверенного пакета используйте экспорт
`computeBundleDigest(root, '.agents/skills/<name>')` из
`scripts/verify-skills.mjs`. Перенесите результат в manifest и включите оба
изменения в один review/коммит. Автоматического режима «доверять текущим файлам»
нет. При неожиданном расхождении разберите причину; не переписывайте manifest
ради зелёной проверки.

`skills-lock.json` сохраняет сведения внешнего установщика об upstream/ref.
Локальный manifest их не заменяет и не доказывает подпись издателя. Локальные
исправления импортированного skill проверяются по новому manifest.

Граница защиты: это preflight рабочего процесса и gate репозитория, а не
перехват загрузчика Codex/Claude и не подпись пакета. Проверка не ограничивает
сетевые/файловые права выполняемого skill, не защищает от подмены самого gate
или manifest вместе с пакетом и не изолирует процесс от конкурентного
изменения дерева пользователем с правом записи. Глобальные skills, плагины,
MCP и транзитивные npm-зависимости не входят в этот manifest. Их происхождение,
версии, разрешения и обновления проверяются отдельно.
