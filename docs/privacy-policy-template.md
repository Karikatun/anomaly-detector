# Политика обработки персональных данных (шаблон)

> **Статус:** черновик. Требует юридической проверки перед публикацией.
> 
> Данный документ — заготовка для передачи юристу. Не является юридической консультацией.

---

## 1. Общие положения

1.1. Настоящий документ определяет политику Оператора в отношении обработки персональных данных пользователей игры **Anomaly Detector** (далее — «Сервис»).

1.2. Оператор:
   - **Наименование:** [ИП/ФИО]
   - **ИНН:** [ИНН]
   - **ОГРНИП:** [ОГРНИП]
   - **Адрес:** [адрес регистрации]
   - **E-mail:** [email для связи]

1.3. Сервис предназначен для аудитории 16+.

1.4. Обработка персональных данных осуществляется в соответствии с:
   - Конституцией РФ;
   - Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных»;
   - иными нормативно-правовыми актами РФ.

## 2. Состав обрабатываемых данных

2.1. Для регистрации и использования Сервиса Оператор обрабатывает:
   - Адрес электронной почты;
   - Имя пользователя (псевдоним);
   - Идентификатор учётной записи в Яндекс ID или VK ID (при входе через эти сервисы);
   - Историю матчей (обезличенные записи о партиях);
   - Техническую информацию: IP-адрес, тип браузера, user-agent.

2.2. Сервис не обрабатывает:
   - Биометрические данные;
   - Данные о состоянии здоровья;
   - Политические, религиозные или философские убеждения.

## 3. Цели обработки

3.1. Персональные данные обрабатываются в целях:
   - Создания и поддержания учётной записи пользователя;
   - Проведения игровых сессий и определения победителя;
   - Отображения истории матчей участникам;
   - Технической поддержки пользователей.

## 4. Правовые основания

4.1. Обработка осуществляется на основании:
   - Согласия пользователя на обработку персональных данных (п. 1 ч. 1 ст. 6 152-ФЗ);
   - Исполнения договора (пользовательского соглашения) (п. 5 ч. 1 ст. 6 152-ФЗ).

## 5. Условия обработки

5.1. Обработка данных производится с использованием вычислительных мощностей на территории Российской Федерации (Яндекс Облако).

5.2. Оператор не передаёт персональные данные третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

5.3. Оператор не осуществляет трансграничную передачу персональных данных.

## 6. Сроки хранения

6.1. Персональные данные хранятся до момента удаления учётной записи пользователем, но не дольше [X] дней после последнего входа.

6.2. Обезличенные записи матчей хранятся бессрочно для обеспечения целостности игровой истории участников матча.

## 7. Права пользователя

7.1. Пользователь имеет право:
   - Получить информацию об обработке своих персональных данных;
   - Требовать уточнения, блокирования или уничтожения своих персональных данных;
   - Отозвать согласие на обработку персональных данных;
   - Требовать удаления учётной записи с анонимизацией игровой истории.

## 8. Удаление учётной записи

8.1. Пользователь может удалить учётную запись через интерфейс Сервиса (раздел «Настройки» → «Удалить аккаунт») либо направив запрос на [email].

8.2. При удалении учётной записи:
   - Адрес электронной почты, имя пользователя и хеш пароля безвозвратно удаляются;
   - Все активные сессии прекращаются;
   - Связанные OAuth-идентификаторы отзываются;
   - Записи матчей сохраняются в обезличенном виде с пометкой «Участник удалён».

8.3. Срок обработки запроса на удаление — не более [30] рабочих дней.

## 9. Меры по обеспечению безопасности

9.1. Оператор принимает необходимые организационные и технические меры для защиты персональных данных от неправомерного доступа, уничтожения, изменения, блокирования, копирования, распространения.

9.2. Применяемые меры включают:
   - Хранение паролей в криптографически стойком хешированном виде (Argon2id);
   - Использование HTTPS для всех соединений;
   - Применение refresh token rotation для защиты сессий;
   - Ограничение доступа к базам данных.

## 10. Заключительные положения

10.1. Оператор вправе вносить изменения в настоящую Политику. Новая редакция вступает в силу с момента её размещения в Сервисе.

10.2. По всем вопросам, связанным с обработкой персональных данных, пользователь может обратиться по адресу [email].
